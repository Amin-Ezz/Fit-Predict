# فیت‌پردیکت (FitPredict)
## پلتفرم پیشرفته تحلیل و پیش‌بینی آمادگی ورزشکاران با هوش مصنوعی

> **FitPredict** یک سامانه تخصصی فیزیولوژی ورزشی و یادگیری ماشین است که ترکیبی از لندینگ‌پیج با طراحی مدرن و داشبورد تعاملی ورزشکار را ارائه می‌دهد. این سامانه با الهام از مدل‌های رگرسیون غیرآزمایشی جکسون (Jackson non-exercise regression) و معماری شبکه عصبی پرسپترون چندلایه (MLP)، ظرفیت قلبی-تنفسی ($VO_2max$)، شاخص آمادگی روزانه (Readiness) و نسبت بار حاد به مزمن (ACWR) را تحلیل و پیش‌بینی می‌کند.

---

## ۱. معماری و ساختار کلی پروژه

پروژه به صورت یک معماری تمیز چندبخشی (Decoupled Architecture) سازمان‌دهی شده است:

```
Fit Predict/
├── .venv/                         # محیط مجازی پایتون (ایزوله)
├── backend/                       # سرویس بک‌اند جنگو (Django REST Framework)
│   ├── manage.py
│   ├── fitpredict_backend/        # تنظیمات هسته جنگو، CORS و مسیرها
│   └── prediction_api/            # اپلیکیشن هوش مصنوعی و سرویس استنتاج
│       ├── ml_model.py            # خط لوله آموزش و استنتاج MLPRegressor
│       ├── mlp_cardio_model.joblib # مدل ذخیره‌شده و متادیتای ارزیابی
│       ├── serializers.py         # اعتبارسنجی ۱۰ ویژگی ورودی به زبان فارسی
│       ├── views.py               # اندپوینت‌های predict/، model-info/ و health/
│       └── urls.py
├── src/                           # فرانت‌اند مدرن و ماژولار (Vanilla JS ES6+)
│   ├── css/
│   │   ├── design-tokens.css      # متغیرهای رنگی، گلس‌مورفیسم و سایه‌ها
│   │   ├── animations.css         # انیمیشن‌ها و پشتیبانی از prefers-reduced-motion
│   │   ├── main.css               # استایل‌های سراسری، فونت وزیرمتن و RTL
│   │   └── dashboard.css          # استایل اختصاصی استپر و کارت‌های داشبورد
│   └── js/
│       ├── utils.js               # تبدیل اعداد به فارسی، فرمت تاریخ شمسی، نوتیفیکیشن
│       ├── charts.js              # نمودارهای Chart.js با Tooltip راست‌به‌چپ
│       ├── animations.js          # انیمیشن‌های ورودی GSAP و ScrollTrigger
│       ├── prediction.js          # کنترلر ویزارد ۴ مرحله‌ای پیش‌بینی
│       ├── dashboard.js           # مدیریت تب‌های داشبورد و ارتباط سرویس‌ها
│       └── services/
│           ├── api.js             # کلاینت ارتباط با سرور با مدیریت Timeout و خطا
│           ├── predictionService.js # سرویس پیش‌بینی با تفکیک واضح حالت Demo و زنده
│           └── athleteService.js  # داده‌های فیزیولوژیک و ترند عملکرد ورزشکار
├── index.html                     # لندینگ پیج اصلی (معرفی، متدولوژی، نمونه زنده)
├── dashboard.html                 # پنل ورزشکار (نمای کلی، استنتاج، وضعیت، تاریخچه، تنظیمات)
├── package.json                   # ابزارهای فرانت‌اند (Vite, Tailwind, GSAP, Chart.js)
├── requirements.txt               # وابستگی‌های پایتون (Django, DRF, scikit-learn, numpy)
├── tailwind.config.js             # پالت رنگی سبز امرالد، لایم و توکن‌ها
└── vite.config.js                 # پیکربندی خروجی چندصفحه‌ای Vite
```

## ۲. هویت بصری و دیزاین سیستم (Design System)

- **جهت سند:** راست‌به‌چپ (`dir="rtl"`) با تایپوگرافی اختصاصی و خوانای **وزیرمتن (Vazirmatn)**.
- **پالت رنگی اصلی:**
  - پس‌زمینه: سفید خالص (`#FFFFFF`) با کنتراست ظریف خاکستری بسیار روشن (`#F8FAFC`).
  - رنگ سازمانی (Primary): سبز امرالد متین (`#168653` و `#126E43`).
  - رنگ مکمل و انرژی‌بخش (Accent): لایم پرانرژی ورزشی (`#CCFF00`).
  - متون: خاکستری تیره با کنتراست استاندارد WCAG AAA (`#0F172A`).
- **جلوه‌های بصری:** گلس‌مورفیسم ملایم (`backdrop-filter: blur(16px)` همراه با بردر سفید نیمه‌شفاف)، سایه‌های نرم بدون استفاده از رنگ‌های تیره خشن، کارت‌های با انحنای مدرن (`rounded-3xl`).
- **انیمیشن‌ها:** حرکت روان با GSAP ScrollTrigger و رعایت کامل تنظیمات دسترسی‌پذیری (`prefers-reduced-motion`).

## ۳. شناسنامه و کارت مدل علمی (Model Card)

| شاخص / ویژگی | مقدار و شرح علمی |
| :--- | :--- |
| **هدف پیش‌بینی (Target)** | برآورد حداکثر اکسیژن مصرفی ($VO_2max$) بر حسب $mL/kg/min$ |
| **روش مدل‌سازی** | ترکیب مدل رگرسیون غیرآزمایشی Jackson et al. با شبکه عصبی پرسپترون چندلایه (MLP) |
| **معماری شبکه عصبی** | `StandardScaler` + `MLPRegressor(hidden_layers=(64, 32, 16), activation='relu', solver='adam')` |
| **تعداد ویژگی‌های ورودی** | ۱۰ متغیر: سن، جنسیت، قد، وزن، سابقه تمرین، جلسات هفتگی، مدت جلسه، خواب، شدت RPE، ضربان استراحت |
| **ضریب تبیین داده‌های آزمون ($R^2$)** | **۰.۹۰۸** (بر روی دسته آزمون مستقل و جداسازی‌شده ۲۰ درصدی) |
| **خطای جذر میانگین مربعات (RMSE)** | **۲.۹۵** $mL/kg/min$ |
| **میانگین خطای مطلق (MAE)** | **۲.۳۷** $mL/kg/min$ |
| **محدودیت و سلب مسئولیت** | این مدل به عنوان یک برآورد غیرتهاجمی ورزشی توسعه یافته است و جایگزین آزمون گازهای تنفسی بالینی (CPET) یا تشخیص پزشکی نیست. |

## ۴. رابط کاربری داشبورد و جریان ۴ مرحله‌ای استنتاج

داشبورد ورزشکار (`dashboard.html`) شامل ۵ بخش مجزا بدون لینک‌های شکسته است:

1. **نمای کلی (Overview):** نمایش کارت‌های شاخص کلیدی (KPIs)، نمودار خطی روند پیشرفت ۸ هفته‌ای، نمودار میله‌ای حجم تمرینات هفتگی و نمودار رادار ۵ وجهی تعادل سیستم فیزیولوژیک.
2. **پیش‌بینی عملکرد (Performance Prediction):**
   - **گام اول (ورود داده‌ها):** فرم دسته‌بندی‌شده و استاندارد با راهنمای مقادیر مجاز و خطاهای اعتبارسنجی فارسی.
   - **گام دوم (بازبینی مقادیر):** جدول خلاصه ۱۰ ویژگی ورودی و امکان بازگشت جهت ویرایش قبل از استنتاج.
   - **گام سوم (استنتاج زنده):** انیمیشن فراخوانی سرویس شبکه عصبی با کنترل وضعیت شبکه و ممانعت از ارسال تکراری.
   - **گام چهارم (نمایش نتایج):** نمایش شاخص $VO_2max$ همراه با برچسب رتبه‌بندی کیفی، امتیاز آمادگی روزانه (Readiness)، نسبت کرنش ACWR، عوامل محدودکننده شناسایی‌شده و توصیه‌های تمرینی کاربردی.
3. **وضعیت ورزشکار (Athlete Status):** مشخصات بیومتریک و الگوهای پایه‌ای ورزشکار با امکان ویرایش درجا و ذخیره‌سازی محلی.
4. **تاریخچه تحلیل‌ها (Prediction History):** فهرست تمام تحلیل‌های ثبت‌شده با امکان فیلتر لحظه‌ای و بازآوری جزئیات هر نتیجه.
5. **تنظیمات (Settings):** مدیریت سوئیچ حالت آزمایشی (Demo Mode)، نمایش آدرس API سرور جنگو و پاکسازی کش محلی.

## ۵. قرارداد رابط برنامه‌نویسی کاربردی (API Contract)

### اندپوینت سلامت سرویس (Health Check)
- **آدرس:** `GET /api/v1/health/`
- **پاسخ موفق:**
```json
{
  "status": "online",
  "service": "FitPredict Neural Prediction Service",
  "version": "1.2.4",
  "backend": "Django 5 + scikit-learn MLP"
}
```

- **آدرس:** `GET /api/v1/model-info/`

## ۶. راهنمای نصب و راه‌اندازی محلی (Getting Started)

### ۱. فعال‌سازی محیط مجازی و اجرای بک‌اند پایتون/جنگو

پروژه دارای محیط مجازی از پیش آماده‌شده در پوشه `.venv` است:

```bash
# ویندوز (PowerShell)
.\.venv\Scripts\Activate.ps1

# اجرای مایگریشن‌های اولیه دیتابیس
python backend/manage.py migrate

# آموزش یا بارگذاری مجدد مدل شبکه عصبی (اختیاری)
python backend/prediction_api/ml_model.py

# اجرای سرور توسعه جنگو بر روی پورت 8000
python backend/manage.py runserver 127.0.0.1:8000
```

### ۲. اجرای فرانت‌اند مدرن (Vite)

در ترمینال مجزا:

```bash
# اجرای سرور فرانت‌اند
npm run dev
```

سامانه بر روی آدرس‌های زیر در دسترس است:
- **معرفی محصول و لندینگ پیج:** `http://127.0.0.1:5173/`
- **داشبورد ورزشکار:** `http://127.0.0.1:5173/dashboard.html`
- **مستندات و API جنگو:** `http://127.0.0.1:8000/api/v1/health/`

## ۷. تست بیلد نهایی و یکپارچگی (Production Build)

برای ساخت نسخه پروداکشن بهینه‌سازی‌شده فرانت‌اند:

```bash
npm run build
```

تمامی بسته‌ها با فشرده‌سازی خودکار و فایل‌های باندل‌شده استاندارد در پوشه `dist/` قرار می‌گیرند.
