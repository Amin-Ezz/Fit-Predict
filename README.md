# فیت‌پردیکت (FitPredict)
## پلتفرم پیشرفته تحلیل و پیش‌بینی آمادگی ورزشکاران با هوش مصنوعی و معماری شبکه عصبی

> **FitPredict** یک سامانه تخصصی فیزیولوژی ورزشی و شبکه عصبی بلادرنگ است که به عنوان یک لندینگ‌پیج مدرن و داشبورد تعاملی بیومتریک ورزشی طراحی شده است. تمام محاسبات هدف‌گذاری متابولیک (پروتئین، آب، الکترولیت‌ها، کالری مصرفی) و ویژوالایزر زنده شبکه عصبی عمیق به صورت ۱۰۰٪ کلاینت‌ساید (Client-Side) در مرورگر اجرا می‌شوند و هیچ وابستگی به سرور بک‌اند ندارند.

---

## ۱. ویژگی‌های کلیدی سامانه

1. **ویژوالایزر زنده معماری شبکه عصبی عمیق (Live Neural Network Visualizer):**
   - پیاده‌سازی کامل روی HTML5 Canvas با انیمیشن‌های روان ۶۰ فریم بر ثانیه.
   - نمایش لایه ورودی ($x_1 \dots x_6$)، لایه‌های پنهان ($n=8$ و $n=6$)، و لایه خروجی ($y_1 \dots y_3$).
   - موج‌های فعال‌سازی نئونی، فریم‌های درخشان و خطوط سیناپسی با کنتراست بالا.
   - قابلیت بررسی و Hover تعاملی نودها و دیاگرام ماتریس وزن‌ها.

2. **سیستم پیش‌بینی بیومتریک لحظه‌ای (Real-time Biometric Prescription):**
   - دریافت آنی شاخص‌های قد، وزن، سن، جنسیت، شدت تمرین (RPE) و خواب.
   - محاسبه و اعمال بلادرنگ نسخه تغذیه، هیدراتاسیون و الکترولیت بر پایه پروتکل‌های فیزیولوژی ورزشی.

3. **هسته اتصال داینامیک مداری (Empower Network):**
   - اتصال هوشمند با خطوط مدار دیجیتال به هسته هوش مصنوعی FitPredict AI Core.
   - کارت‌های تعاملی سه حوزه تخصصی (تغذیه تطبیقی، بازتنظیم پویا، هیدراتاسیون پیشرفته).

4. **اسلایدر ورزشکاران شاخص (Preset Athlete Carousel):**
   - بارگذاری سریع پروفایل‌های ورزشی از پیش آماده برای تست عملکرد سیستم.

5. **طراحی مدرن و سبک بصری:**
   - تم Liquid Mint (`#64C800`) و Emerald (`#00E575`) با دارک‌مود عمیق (`#002518`).
   - اسکرول نرم با Lenis و افکت‌های تعاملی با GSAP و Lucide Icons.

## ۳. اجرای محلی پروژه (Local Development)

### پیش‌نیازها
- **Node.js:** نسخه ۱۸ یا بالاتر
- **npm:** نسخه ۹ یا بالاتر

### نصب وابستگی‌ها و اجرا
```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. اجرای سرور توسعه فرانت‌اند
npm run dev
```

سامانه بر روی آدرس محلی `http://localhost:5173/` اجرا خواهد شد.

---

## ۴. ساخت نسخه نهایی پروداکشن (Production Build)

برای تولید خروجی ایستا و فشرده جهت بارگذاری در سرور یا هاست:
```bash
npm run build
```

خروجی در پوشه `dist/` با فشرده‌سازی حداکثری و استایل‌های بهینه‌شده ذخیره خواهد شد.

---

## ۵. راهنمای دیپلوی در Vercel

پروژه به صورت کامل برای استقرار روی **Vercel** آماده است:

1. **انتقال به گیت‌هاب:** پروژه را در مخزن GitHub خود Push کنید.
2. **اتصال در پنل Vercel:**
   - وارد [Vercel](https://vercel.com) شوید و دکمه **"Add New Project"** را بزنید.
   - مخزن گیت‌هاب `Fit Predict` را انتخاب کنید.
3. **تنظیمات بیلد (به صورت پیش‌فرض خودکار شناسایی می‌شود):**
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. کلیک روی دکمه **Deploy**. سامانه در چند ثانیه منتشر شده و آدرس دامنه فعال تحویل می‌گردد.
